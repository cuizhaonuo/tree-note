# 树形笔记（tree-note）

**Status:** ready-for-agent

## Problem Statement

我过去每天在语雀写一段“今天做了什么”。这是一整段文字，看不出事件的发生顺序，也看不出哪个想法是在做哪件事时冒出来的，必须读完整段才能理解。

## Solution

一个以键盘操作为主的 Web 笔记应用。每篇笔记有一个标题和一棵自上而下的树：

- 每个结点是一个**事件**或一个**想法**；
- 父 → 子表示“由父结点引发，且发生得更晚”，所以深度就是时间；
- 兄弟结点是同一个父结点引出的并行分支，从左到右按时间排列。

选中结点按 Enter 新建子结点，按方向键在结点间移动。笔记以 Markdown 文件的形式保存在本地文件夹里，数据完全归自己所有，可以用 git 或网盘同步。

## User Stories

1. 作为用户，我想授权一个本地文件夹作为笔记库，这样所有笔记都是我自己能管理的普通文件。
2. 作为用户，我想看到笔记库里所有笔记的列表，按最近修改时间排序，这样能快速回到正在进行的项目。
3. 作为用户，我想按 Ctrl+N 新建笔记：先输入标题，确认后自动创建一个空的根结点并进入编辑状态，这样能立即开始记录。
4. 作为用户，我想让笔记的标题和根结点彼此独立：标题是笔记的名字，根结点是树里的第一个事件或想法。
5. 作为用户，我想看到一棵自上而下的树，根结点在最上面，这样一眼就能看清事情的先后和分支。
6. 作为用户，我想在选中结点时按 Enter 新建一个子结点并立即编辑它，这样能按时间顺序往下记录。
7. 作为用户，我想在选中结点时按 Shift+Enter 新建一个兄弟结点，这样记下 B1 之后能马上接着记 B2。
8. 作为用户，我想在编辑时按 Enter 或 Esc 确认并回到选择状态，这样连按两次 Enter 就能继续写下一个子结点。
9. 作为用户，我想在编辑时按 Shift+Enter 在文本内换行，这样一个结点可以写多行内容。
10. 作为用户，我想让确认时内容为空的结点被自动删除，这样误触不会留下垃圾结点。
11. 作为用户，我想按 F2 或双击来编辑已有结点。
12. 作为用户，我想在结点文本里使用行内 Markdown（加粗、链接、行内代码），这样能记下命令、路径和指标。
13. 作为用户，我想按 ↑ 移动到父结点。
14. 作为用户，我想按 ↓ 移动到上次访问过的那个子结点（从来没访问过的话，就到第一个子结点），这样在一条分支上来回移动很顺手。
15. 作为用户，我想按 ← 或 → 移动到屏幕上同一层相邻的结点，并且能跨过不同的子树。
16. 作为用户，我想让选中的结点自动滚动到视野中央，这样在大树里不会迷路。
17. 作为用户，我想让新建的结点默认是“事件”，并能按 `i` 在事件和想法之间切换，这样可以区分“做了什么”和“想到了什么”。
18. 作为用户，我想让“想法”用明显不同的样式显示（虚线边框或灯泡图标），这样一眼就能看出哪些是悬而未决的想法。
19. 作为用户，我想让每个结点自动记录创建时间，这样不用手动写时间。
20. 作为用户，我想按 `t` 修改结点的时间，这样事后补记时也能填上准确的时间。
21. 作为用户，我想在子结点的时间早于父结点时看到标红提示，但仍然允许保存，这样补记不会被卡住，错误也不会被忽略。
22. 作为用户，我想让结点显示时间，并且每天第一个出现的结点额外显示日期，这样跨天的项目树也能看出日期边界。
23. 作为用户，我想让兄弟结点从左到右自动按时间排序，修改时间后位置也跟着变化。
24. 作为用户，我想按 Delete 删除一个结点及其整棵子树，删除前需要确认。
25. 作为用户，我想让根结点不能被删除（只能清空文字），这样树永远有一个起点；要删除整棵树，就删除整篇笔记。
26. 作为用户，我想先按 `x` 剪切一个结点（连同它的子树），再到目标结点按 `v` 粘贴为它的子结点，这样挂错位置时可以纠正。
27. 作为用户，我想按 Ctrl+Z 撤销最近的操作（在本次打开页面期间有效）。
28. 作为用户，我想按空格折叠或展开一个结点的子树，这样可以隐藏已经结束的分支。
29. 作为用户，我想让方向键导航跳过被折叠的结点。
30. 作为用户，我想缩放和拖动画布，这样能看清整棵大树，也能放大细节。
31. 作为用户，我想按 Ctrl+R 或点击标题来重命名笔记，文件名同步变化，重名时自动加 `-2` 之类的后缀。
32. 作为用户，我想在笔记列表里删除一篇笔记（需要确认），对应的文件也会被删除。
33. 作为用户，我想让每次改动后大约 1 秒自动保存到文件，这样不用担心丢失内容。
34. 作为用户，我想让笔记文件是人能直接读懂的 Markdown 嵌套列表，这样即使不用这个应用，文件也能读、能 grep、能在 git 里看 diff。
35. 作为用户，我想全文搜索所有笔记里所有结点的文字，点击结果就打开对应笔记并选中那个结点，这样能回答“我哪天试过那个 backbone”。

## Implementation Decisions

- **平台**：浏览器 Web 应用，只支持 Chrome 和 Edge，因为要使用 File System Access API 读写用户授权的本地文件夹。没有后端。
- **技术栈**：Vite + React + TypeScript。布局用 d3-hierarchy 的 tidy tree 算法（自上而下）。连线用 SVG 绘制，结点用 HTML 渲染（方便编辑多行文本）。缩放和平移用 d3-zoom。不使用 React Flow，因为这里的布局完全由树结构决定。
- **领域模型**：
  - 一篇笔记包含一个标题和一棵树。标题不是结点。
  - 树有且只有一个根结点。根结点和其他结点完全一样，只是没有父结点，也不能删除。
  - 结点包含：类型（事件或想法）、时间戳（完整的日期和时间，自动生成，可以修改）、文本（多行，支持行内 Markdown）、子结点列表。
  - 兄弟结点的顺序由时间戳决定，不单独存储顺序。
- **文件格式**：每篇笔记一个 `.md` 文件，文件名由标题生成，重名时加 `-2` 等后缀，改标题时同步重命名文件。格式如下（这是约定好的数据格式）：

  ```markdown
  # 训练 wheat 检测模型

  - [事件 2026-09-30 14:32] 跑 baseline
    - [想法 2026-09-30 14:40] 试试更大的 backbone
    - [事件 2026-09-30 15:10] 改 `lr=1e-4` 重跑
      结果 mAP **42.1**，比之前高
      - [事件 2026-10-01 09:05] 看可视化
  ```

  规则：
  - 一级标题是笔记标题；下面唯一的顶层列表项是根结点；缩进的列表项是子结点。
  - 前缀 `[类型 YYYY-MM-DD HH:MM]` 中的类型写中文“事件”或“想法”。
  - 多行文本用和列表项正文对齐的续行表示。
  - 解析后再写回，内容必须保持不变（round-trip 稳定）。
- **核心模块**：一个不依赖界面的纯逻辑模块，界面只是它的一层薄壳。它对外提供：
  - **格式**：Markdown 和笔记之间的解析与写回。
  - **命令**：`applyCommand(状态, 命令) → 新状态`。命令包括新建子结点、新建兄弟结点、修改文本、删除子树、剪切/粘贴、切换类型、修改时间、重命名标题，也包括撤销。“确认时内容为空就删除结点”和“根结点不可删除”也在这里实现。
  - **导航**：输入树、当前选中结点、方向、界面状态（折叠集合、每个结点上次访问过的子结点）和布局结果，输出新的选中结点。
  - **派生信息**：兄弟结点排序、每天第一个结点的日期标记、子结点早于父结点的违规标记、全文搜索的匹配结果。
- **界面状态**：选中结点、编辑状态、折叠集合、每个结点上次访问过的子结点、撤销历史都只保存在内存里，不写进 `.md` 文件。
- **保存**：状态变化后防抖约 1 秒自动写回文件。
- **键盘映射**：

  | 状态 | 按键 | 动作 |
  |---|---|---|
  | 选择 | ↑ / ↓ / ← / → | 移动到父结点 / 上次访问过的子结点 / 屏幕上同一层相邻的结点 |
  | 选择 | Enter / Shift+Enter | 新建子结点 / 新建兄弟结点 |
  | 选择 | F2 或双击 | 编辑结点 |
  | 选择 | `i` / `t` | 切换类型 / 修改时间 |
  | 选择 | Delete | 删除子树（需要确认） |
  | 选择 | `x` 然后 `v` | 剪切，再粘贴为子结点 |
  | 选择 | 空格 | 折叠或展开子树 |
  | 编辑 | Enter 或 Esc | 确认 |
  | 编辑 | Shift+Enter | 在文本内换行 |
  | 任意 | Ctrl+Z / Ctrl+N / Ctrl+R | 撤销 / 新建笔记 / 重命名标题 |

## Testing Decisions

- **只有一个测试切入点：核心模块**，用 Vitest 编写测试。只测外部行为：给定输入的状态和命令（或按键），断言输出的状态、选中的结点和写回的 Markdown，不断言内部实现。
- 需要覆盖的内容：
  - 格式：解析与写回，包括 round-trip 稳定性、多行文本、行内 Markdown 原样保留、格式错误时的处理。
  - 命令：每个命令，以及它们与撤销的组合。
  - 导航：“上次访问过的子结点”规则、跨子树的 ←/→、跳过折叠的结点。
  - 派生信息：排序、日期标记、违规标记、搜索。
- 读写文件和画布渲染不写单元测试，靠每个任务的验收标准手动验证。以后如果需要，可以再补 Playwright 端到端测试。
- 仓库里目前还没有已有的测试可以参考，这些测试是第一批。

## Out of Scope

- 导入语雀的历史笔记。
- 手机端，以及 Firefox 和 Safari。
- 多设备同步和后端（由用户自己用 git 或网盘同步）。
- 图片、代码块等富内容。
- 想法的状态流转（待办、已执行、放弃）。
- 文件夹或分组（以后可以用子目录实现）。
- 用 LLM 自动整理结点。
- 打包成桌面应用（以后可以用 Tauri 包装）。
- 跨会话保留撤销历史，以及把折叠状态写进文件。
