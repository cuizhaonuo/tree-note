# 06: 折叠与缩放

**What to build:** 在很大的树里，用户可以折叠已经结束的分支，也可以缩放和拖动画布来查看全局或放大细节。规格见 `../spec.md`。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 选择状态下按空格，折叠或展开当前结点的子树；折叠后的结点上有标识，并显示被隐藏的结点数量
- [ ] 被折叠的结点不参与布局，方向键导航也会跳过它们
- [ ] 画布可以用鼠标滚轮缩放、用拖动平移（使用 d3-zoom）；缩放后，选中结点的自动居中仍然有效
- [ ] 折叠状态只保存在内存里，不写进文件
- [ ] 导航跳过折叠结点的逻辑有 Vitest 测试
