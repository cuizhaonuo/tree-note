# 08: 全文搜索

**What to build:** 用户在笔记列表的搜索框中输入关键词，看到所有笔记里所有匹配的结点（显示所在笔记的标题、结点的时间和包含关键词的文本片段）。点击一条结果，就打开对应笔记并选中、居中那个结点。规格见 `../spec.md`。

**Blocked by:** 02

**Status:** done（2026-10-01 浏览器手动验收通过）

- [x] 搜索覆盖文件夹中所有笔记的所有结点文字，也覆盖标题
- [x] 每条结果显示所在笔记的标题、结点的时间，以及高亮了关键词的文本片段
- [x] 点击结果后打开对应笔记，选中并居中那个结点；如果 06 已经完成、而它位于被折叠的子树里，先把沿途的折叠展开
- [x] 搜索的匹配逻辑在核心模块中实现，有 Vitest 测试

## Comments

- 实现决定：用空格隔开的多个关键词必须全部出现，不区分大小写，每一处出现都高亮。片段把多行文本连成一行，太长时只保留第一处匹配附近的一段，截掉的地方用“…”标出。
- 实现决定：匹配标题时结果指向根结点，时间显示根结点的时间。打开这种结果时根结点留在视野顶部，和从笔记列表打开一样，不居中。
- 实现决定：结果用路径（每一层在文件里的下标）加上结点的时间和文本指明结点，因为结点 id 每次解析都重新生成。搜索之后笔记又被改过、结点对不上时，只给出提示，不会选中别的结点。
- 打开着的笔记用内存里的内容搜索，自动保存还没写到文件的改动也能搜到；其他笔记在排队的写入和改名完成后从文件读。格式有误或读不了的笔记会被跳过。
- 搜索框里 Enter 打开第一条结果，Esc 清空；最多显示 200 条结果。
