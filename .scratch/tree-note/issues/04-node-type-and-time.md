# 04: 类型与时间

**What to build:** 用户可以把结点在事件和想法之间切换，可以修改结点的时间。树会根据时间自动排列兄弟结点，标出每天的第一个结点，并提示时间顺序上的矛盾。规格见 `../spec.md`。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 选择状态下按 `i`，结点在事件和想法之间切换，样式随之变化，并写回文件
- [ ] 选择状态下按 `t` 弹出时间编辑框（可以改日期和时间），确认后更新时间并写回文件
- [ ] 兄弟结点从左到右按时间排序；修改时间后，结点的位置随之变化
- [ ] 每个结点显示时间；每天第一个出现的结点（按时间计算）额外显示日期
- [ ] 子结点的时间早于父结点时，这个结点标红提示，但仍然允许保存
- [ ] 切换类型、修改时间、兄弟排序、日期标记、违规标记都在核心模块中实现，有 Vitest 测试
