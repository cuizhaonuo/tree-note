# 02: 键盘导航

**What to build:** 在打开的笔记中，用户可以完全用方向键在结点之间移动，选中的结点有高亮，并自动滚动到视野中央。规格见 `../spec.md`。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 打开笔记时默认选中根结点
- [ ] ↑ 移动到父结点；在根结点上按 ↑ 不动
- [ ] ↓ 移动到这个结点上次访问过的子结点；从来没访问过的话，移动到第一个子结点（时间最早的那个）；没有子结点时不动
- [ ] ← 和 → 按屏幕上同一层移动到相邻结点，可以跨过不同的子树；到了这一层的两端就不动
- [ ] 选中结点变化时，画布自动把它滚动到中央
- [ ] 导航逻辑放在核心模块里（输入树、当前选中结点、方向、界面状态和布局结果，输出新的选中结点），有 Vitest 测试覆盖“上次访问过的子结点”规则和跨子树移动
