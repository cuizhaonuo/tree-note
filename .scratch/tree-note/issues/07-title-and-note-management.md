# 07: 标题与笔记管理

**What to build:** 用户可以重命名笔记（文件名同步变化），也可以在列表里删除笔记。规格见 `../spec.md`。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Ctrl+R 或点击画布顶部的标题进入标题编辑，确认后更新文件里的一级标题，并同步重命名文件；如果文件重名，自动加 `-2` 等后缀
- [ ] 重命名只改标题，不影响根结点
- [ ] 笔记列表按最近修改时间排序，编辑某篇笔记之后，它会移到列表顶部
- [ ] 可以在列表里删除笔记，删除前需要确认，确认后对应的文件也被删除
- [ ] 重命名标题的命令在核心模块中实现，有 Vitest 测试（包括撤销）
