# 07: 标题与笔记管理

**What to build:** 用户可以重命名笔记（文件名同步变化），也可以在列表里删除笔记。规格见 `../spec.md`。

**Blocked by:** 03

**Status:** done（2026-10-01 浏览器手动验收通过）

- [x] Ctrl+R 或点击画布顶部的标题进入标题编辑，确认后更新文件里的一级标题，并同步重命名文件；如果文件重名，自动加 `-2` 等后缀
- [x] 重命名只改标题，不影响根结点
- [x] 笔记列表按最近修改时间排序，编辑某篇笔记之后，它会移到列表顶部
- [x] 可以在列表里删除笔记，删除前需要确认，确认后对应的文件也被删除
- [x] 重命名标题的命令在核心模块中实现，有 Vitest 测试（包括撤销）

## Comments

- 实现决定：标题会去掉首尾空白，空标题被拒绝并给出提示。
- 实现决定：新旧文件名只差大小写时不改名，直接写回旧文件。在不区分大小写的文件系统上新旧是同一个文件，先建新文件再删旧文件会把它删掉。
- 改名时先写新文件再删旧文件；如果删除旧文件失败，会留下两个文件，界面会显示错误。
