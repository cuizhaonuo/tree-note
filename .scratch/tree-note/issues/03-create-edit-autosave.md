# 03: 新建与编辑，并自动保存

**What to build:** 用户可以新建笔记，用 Enter 和 Shift+Enter 不断长出新结点并编辑文本，所有改动约 1 秒后自动写回文件。这是第一个真正能用来记笔记的版本。规格见 `../spec.md`。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Ctrl+N 新建笔记：先输入标题，确认后在文件夹中创建对应的 `.md` 文件（文件名由标题生成，重名时加 `-2` 等后缀），自动创建一个空的根结点（类型为事件，时间为当前时间）并进入编辑状态
- [ ] 选择状态下按 Enter 新建子结点，按 Shift+Enter 新建兄弟结点（在根结点上按 Shift+Enter 不做任何事），新结点立即进入编辑状态
- [ ] 编辑状态下按 Enter 或 Esc 确认并回到选择状态；按 Shift+Enter 在文本内换行
- [ ] 确认时如果结点内容为空，就自动删除这个结点，并选中它的父结点；根结点例外，不会被删除
- [ ] F2 或双击可以编辑已有结点
- [ ] 状态变化后防抖约 1 秒自动写回文件；刷新页面并重新打开笔记后，内容完整
- [ ] 新建和编辑相关的命令在核心模块中实现为 `applyCommand`，有 Vitest 测试
