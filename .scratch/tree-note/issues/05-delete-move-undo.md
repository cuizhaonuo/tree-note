# 05: 删除、移动与撤销

**What to build:** 用户可以删除一个结点及其子树，可以把挂错位置的结点移到正确的父结点下，还可以撤销误操作。规格见 `../spec.md`。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 选择状态下按 Delete 弹出确认框，确认后删除这个结点及其整棵子树，并选中它的父结点
- [ ] 根结点不能删除：在根结点上按 Delete 时给出提示，不做任何修改
- [ ] 按 `x` 标记要剪切的结点（界面上有明显标识），移到目标结点后按 `v`，被剪切的结点连同子树成为目标结点的子结点；不能粘贴到它自己或它自己的子树里；根结点不能被剪切
- [ ] Ctrl+Z 可以撤销最近的操作（新建、编辑、删除、移动、切换类型、修改时间、重命名），可以连续撤销；撤销后的结果也会自动保存
- [ ] 撤销历史只保存在内存里，刷新页面后清空
- [ ] 删除、剪切/粘贴、撤销都在核心模块中实现，有 Vitest 测试，包括撤销与其他各个命令的组合
