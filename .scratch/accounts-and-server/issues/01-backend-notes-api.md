# 01: 后端笔记接口（无登录）

**What to build:** 用 Hono 搭建 Node.js + TypeScript 后端，提供笔记的全部接口（暂不要求登录，先按单一数据目录工作）：列出笔记（文件名 + 最后修改时间，按修改时间倒序）、读取笔记（全文 + 版本号）、新建笔记（传标题和全文，服务器按核心模块规则生成不重名文件名，返回文件名和版本号）、写回笔记（传全文、基于的版本号、可选新标题；标题变化时在同一次操作里按原规则完成重命名，包括只差大小写时直接写回原文件；版本不一致返回 409 不写入）、删除笔记、全文搜索（复用核心模块，只返回匹配结果）。版本号取文件内容的哈希，外部改动（手动拷入、git 恢复）也会被识别为版本变化。服务器只接受符合文件名规则的名字（不含路径分隔符或 `..`，以 `.md` 结尾）。数据目录位置由配置决定。本机开发可用一条命令同时启动前端和后端，使用本地临时数据目录。复用核心模块（格式解析与写回、文件名生成、搜索），不复制逻辑。用 Hono 进程内请求能力写 HTTP 测试，每个测试使用独立临时数据目录。

**Blocked by:** None (can start immediately)
