# 03: 断网暂存与冲突处理

**What to build:** 让自动保存在网络不稳定和多设备场景下不丢内容。保存失败（网络错误或 5xx）时，把未保存的全文按"用户 + 文件名"暂存到 localStorage，界面显示"未保存"，然后按退避间隔自动重试，重试成功后清除暂存并恢复"已保存"。打开一篇笔记时如果发现 localStorage 里有它的暂存内容，就恢复暂存内容并立即尝试保存。收到 409 时停止自动保存，提示"这篇笔记在别处被修改过，请刷新"，暂存内容保留不自动丢弃。有暂存内容时关闭或刷新页面，再次打开这篇笔记能恢复并继续保存。这套状态逻辑（暂存、重试、409 停止、打开恢复）写成不依赖 React 的纯逻辑模块，网络请求和 localStorage 通过参数注入，用 Vitest 覆盖。
