# 04: 登录与会话（后端 + 创建管理员脚本）

**What to build:** 给服务器加上账号体系。账号和会话存在数据目录下的 SQLite 文件（优先 `node:sqlite`）。用户表：id、用户名（唯一）、密码哈希（`crypto.scrypt`，每密码独立随机盐）、角色（admin/user）、状态（active/disabled）、创建时间、最后登录时间；会话表：高熵随机会话 id、用户 id、过期时间；登录失败按用户名和按 IP 分别计数。接口：登录（成功下发 HttpOnly、SameSite=Lax cookie，纯 HTTP 阶段不加 Secure）、退出、获取当前用户（用户名、角色）、修改自己的密码（需要旧密码）。会话 30 天有效、滚动续期（剩余不足一半才写库续期）。同一用户名或同一 IP 在 15 分钟内连续失败 5 次锁定 15 分钟，锁定期间即使密码正确也拒绝；登录成功清零该用户名计数。错误提示统一为"用户名或密码错误"，不区分是哪个错。每次请求校验用户状态，被禁用者即使会话有效也一律拒绝。改密后删除该用户其他所有会话；重置/禁用（管理接口在 07）也要删除全部会话——删除某用户全部会话的能力本票就要具备。笔记接口改为按当前登录用户的目录隔离：每个用户一个目录 `<数据目录>/users/<userId>/`，任何接口都无法跨用户读写；未登录请求一律 401。另提供命令行脚本创建首个管理员（传入用户名、交互式输入密码）。HTTP 测试覆盖认证全路径，时间可注入，不真的等待 15 分钟。
