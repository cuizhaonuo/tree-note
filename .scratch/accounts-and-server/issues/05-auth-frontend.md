# 05: 登录页与会话前端行为

**What to build:** 前端接上认证。新增登录页：未登录时打开任何页面都被带到登录页，登录成功后回到笔记界面；登录一次 30 天内不用再登录（滚动续期由服务器完成，前端无感）。提供退出登录入口。新增修改密码界面（输入旧密码和新密码）。任何接口返回 401 时，前端保留当前未保存的内容（含 localStorage 暂存），弹出登录界面，重新登录后继续保存，编辑不中断。被禁用时下一次请求即被退出并看到"账号已被禁用"的明确提示，而不是表现为网络错误。登录失败只显示"用户名或密码错误"；锁定时显示稍后再试。

**Blocked by:** 02-frontend-switch-to-api, 04-auth-backend-and-admin-cli

- [x] 可在界面上修改密码（需旧密码），改完后其他设备上的登录失效
