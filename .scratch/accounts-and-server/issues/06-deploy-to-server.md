# 06: 部署上线

**What to build:** 让应用跑在腾讯云服务器上并通过公网 IP 可用。Node 服务同时提供 `/api/*` 接口和构建好的前端静态文件，只监听本机端口；Caddy 监听 80 端口反向代理（纯 HTTP，通过 IP 访问；以后有域名只改 Caddy 配置即可启用 HTTPS）。应用由 systemd 管理：开机自启、崩溃后自动重启。数据目录、监听端口等配置放在服务器上的一个环境配置文件里，由 systemd 加载，不进代码仓库。提供一条命令的部署脚本：拉取最新代码、安装依赖、构建、重启服务。服务器通过自己配置好的代理访问 GitHub。需要人工完成的步骤（SSH 登录、安全组放行 80 端口、填写配置文件、用命令行脚本创建首个管理员）用交互式向导脚本引导。本票需要作者提供服务器的公网 IP 和登录方式。Caddy、systemd、部署脚本不写单元测试，靠验收标准手动验证。
