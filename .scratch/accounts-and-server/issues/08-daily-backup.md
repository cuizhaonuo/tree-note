# 08: 每日备份（git commit + COS）

**What to build:** 服务器上的笔记数据每天自动备份一次，由定时任务执行：(1) 先用 SQLite 备份机制导出一致的数据库副本，再对整个数据目录（含 SQLite 文件）做 git commit，没有变化就跳过——误删或改坏内容后能查历史并恢复；(2) 把数据目录打包上传到 COS 私有存储桶，按日期命名——服务器整个丢失时也能恢复；(3) 存储桶配置生命周期规则自动删除 30 天前的备份；(4) 任何一步失败以非零状态退出并把错误写入系统日志，不悄悄失败。COS 使用 CAM 子用户密钥，该子用户只有向这一个桶上传对象的权限；密钥只保存在服务器的环境配置文件里，不进代码仓库。存储桶设为私有读写。本票需要作者提供 COS 存储桶域名（含桶名和地域）；密钥由作者在服务器上亲手填写。CAM 子用户创建、桶的生命周期规则等人工步骤并入 06 的交互式向导（或本票的向导扩展）。备份脚本不写单元测试，靠验收标准手动验证。
