# 07: 管理界面

**What to build:** 管理员用和普通用户相同的方式登录，进入同样的笔记界面，但多一个"管理"入口；普通用户看不到入口，直接访问管理页面或管理接口一律 403。管理页面包含：用户列表（用户名、角色、状态、创建时间、最后登录时间、笔记数量、占用空间——数量和空间在查询时统计目录得到，不存储）；创建用户（填用户名、初始密码、角色，用户名已存在时显示明确错误）；重置某用户密码（重置后该用户所有会话立即失效）；禁用/启用用户（禁用后其所有会话立即失效且无法再登录，禁用不删除笔记）。管理员不能禁用自己，也不能修改自己的角色。不提供任何读取其他用户笔记内容的接口或页面——管理员只能看到数量和占用空间。管理接口用进程内 HTTP 测试覆盖（含权限、统计正确性、自锁保护）。

**Blocked by:** 05-auth-frontend

- [x] 重置密码后该用户在所有设备上的登录立即失效，可用新密码登录

- [x] 不能禁用自己、不能修改自己的角色
- [x] 管理员没有任何途径读到其他用户的笔记内容（接口和页面都没有）
