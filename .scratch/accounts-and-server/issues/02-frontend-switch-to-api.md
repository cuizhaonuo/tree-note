# 02: 前端切换到服务器接口

**What to build:** 把前端直接读写本地文件夹的笔记库层整体替换为调用服务器接口的客户端，对界面暴露的能力保持不变（列出、读取、新建、写回、重命名、删除）。笔记不再用文件句柄标识，改用文件名标识。File System Access API 相关代码整体删除，不保留两种模式并存。替换后体验与原来一致：打开应用直接看到按最近修改时间倒序的笔记列表；键盘操作、树的显示、撤销、折叠、缩放不变；新建、重命名、删除行为和原来一样（文件名由标题生成、重名加后缀由服务器完成）；每次改动约 1 秒防抖自动保存，每次保存带上基于的版本号；界面显示保存状态（已保存 / 保存中 / 未保存）；全文搜索改为调用服务器接口，点击结果仍打开对应笔记并选中那个结点。由于不再依赖 File System Access API，Chrome、Edge、Firefox、Safari 桌面版都应可用（手动验证）。

**Blocked by:** 01-backend-notes-api

- [x] 键盘操作、撤销、折叠、缩放、全文搜索行为与原来一致，搜索结果点击后选中对应结点
